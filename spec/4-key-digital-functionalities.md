# 4 Key Digital Functionalities

Key Digital Functionalities describe public-purpose capabilities, not endpoints
or product features. Give each KDF a stable ID of the form
`{bb-code}-KDF-{number}` and do not renumber published IDs. Normative, testable
obligations derived from each KDF belong in Section 6.

The following KDFs belong to the template reference domain. Replace them when
creating a real BB.

## BB-TPL-KDF-001 Manage reference records

An authorised actor can discover, create, and retrieve reference records. This
demonstrates a conventional resource lifecycle without imposing a domain model.

## BB-TPL-KDF-002 Run long-running work

An authorised system can request work that completes asynchronously and can
observe or cancel that work through a standard Operation resource.
